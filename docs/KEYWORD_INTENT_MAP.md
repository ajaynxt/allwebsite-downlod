# Keyword and intent map

| Page | Primary intent | Natural query themes | Conversion |
|---|---|---|---|
| `/` | Use a downloader | link downloader, video downloader, Reel downloader, audio downloader, best quality | Link analyzed → direct device download |
| `/supported-sites` | Check compatibility | Pinterest video Pin download, public Reel support, supported video sites | Return to downloader |
| `/privacy` | Trust | downloader privacy, temporary files | Trust/support |
| `/terms` | Responsible use | permitted content download, downloader terms | Rights confirmation |
| `/copyright` | Rights contact | copyright notice, takedown contact | Complete notice |

Avoid near-duplicate pages for every platform. Add a dedicated platform guide only when it answers unique user questions with tested screenshots, limitations and support evidence.

## On-site query aliases

The platform finder recognizes brand short forms and common misspellings such as `yt`, `youtub`, `insta`, `instgram`, `pintrest`, `facebok`, `tictok`, `tweeter`, `redit`, `linkdin` and `spotlite`. Fuzzy edit-distance matching covers additional minor spelling errors without sending the query to a server.
